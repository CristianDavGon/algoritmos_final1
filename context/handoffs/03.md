## Qué se completó

La Fase 3 tenía como objetivo extender QNodes al caso k-particiones con k ∈ {2,3,4,5}, reutilizando el oracle Queyranne y el MAO existentes. Todo fue completado:

- **`KQNodes` implementado**: `code/QNodes/src/strategies/kqnodes.py` — criterio C4 (MinHeap por φ_local), oracle restringido con remapeo de máscaras, caché por bloque, cálculo de Φ* con una sola EMD al final.
- **Variante C1 conservada**: `criterio='C1'` como parámetro en `aplicar_estrategia()` para A/B testing experimental.
- **Regresión k=2 pasa**: KQNodes(k=2) == QNodes para n ∈ {5,8,10}, tolerancia 1e-9. 13/13 casos verificados en `test_regresion_k2_igual_qnodes`.
- **Monotonicidad verificada**: φ(k+1) ≥ φ(k) para k ∈ {2,3,4} — dirección correcta. Verificado para C4 y C1 en `test_monotonicidad_creciente_n5`.
- **Gap vs BruteForce medido**: gap = φ_greedy − φ* ≥ 0 para k ∈ {3,4}, n=5. Tasa de acierto exacto reportada en `test_ab_c1_vs_c4_n5`.
- **A/B testing C1 vs C4**: comparación de gap medio y % acierto ejecutada para k ∈ {3,4}. Evidencia requerida por rúbrica.
- **CSVs generados**: `code/QNodes/results/kqnodes/resultado__N{n}_{m}_{k}.csv` para k ∈ {2,3,4,5}, n ∈ {5,20}.
- **Calidad**: mypy limpio en `kqnodes.py`; docstrings Google/NumPy en todos los métodos públicos; cobertura ≥ 85%.

## Decisiones de diseño clave (para quien retome el trabajo)

| Decisión | Detalle |
|----------|---------|
| C4 como criterio principal | Minimiza Φ* greedy: elige el corte de menor φ_local. Ver D3-01. |
| Caché por bloque | No compartir caché entre bloques Pi y Pj: las máscaras locales colisionan. Ver D3-02. |
| Remapeo de máscaras | Pi = {g₀ < g₁ < ... < g_{m−1}} → índice local r = posición en Pi. Ver `_oracle_restringido()`. |
| EMD una sola vez | El oracle es solo proxy de ranking; EMD completa solo al final. Ver D3-04. |
| Desempate C4 | Tupla (φ_local, −|Pi|, min_index) garantiza determinismo. Ver D3-03. |

## Hallazgos experimentales (para Fase 6)

| Hallazgo | Detalle |
|----------|---------|
| Monotonicidad gratuita por construcción | Cada corte greedy añade Δφ = φ_local ≥ 0; la secuencia es no decreciente por definición. |
| Gap k≥3 no necesariamente 0 | KQNodes no es óptimo global para k≥3. Gap real a medir en Fase 6 con más sistemas. |
| C4 mejor que C1 en gap | C1 ignora φ_local completamente; C4 minimiza el incremento greedy. Verificado en A/B test. |
| Speedup KQNodes k=2 vs QNodes | Igual que QNodes para k=2 (mismo código path). Datos de referencia en `SDD-2/implementation.md`. |
